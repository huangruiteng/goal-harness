# Deprecated benchmark stack

This directory preserves the pre-reset benchmark implementation and research
history for source archaeology. It is not an active LoopX runtime surface.

The archived tree keeps its former repository-relative layout where practical:

- `loopx/` contains legacy adapters, read models, ledgers, and Goal helpers;
- `scripts/` contains benchmark-family runners and host bridges;
- `examples/`, `tests/`, and `regression/` contain their historical validation;
- `docs/` contains dated research packets and the previous developer workflow.

Do not import or extend this code. When current practice demonstrates a reusable
caller outcome, reimplement the smallest provider-neutral contract in
`loopx/capabilities/benchmark_toolkit/` or the active [`benchmark/`](../../benchmark/README.md)
research workspace. Copy behavior only after characterization; do not restore a
legacy directory merely to preserve its old abstraction.

The archive grants no runner, model, task-data, verifier, upload, submission, or
publication authority. Historical commands may be stale or unsafe and are not
covered by current validation.
