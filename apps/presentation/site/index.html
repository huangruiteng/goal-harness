Manual fallback

Prefer the shell? Install LoopX manually.

Use this path when your current agent cannot run shell commands. The same official installer registers lightweight command entries for supported hosts.

terminal
$ curl -fsSL https://raw.githubusercontent.com/huangruiteng/loopx/main/scripts/install-from-github.sh | bash
$ export PATH="$HOME/.local/bin:$PATH"
$ loopx doctor
$ cd /path/to/your-project
$ loopx connect
$ loopx status
